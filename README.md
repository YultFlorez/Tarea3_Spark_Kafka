# Tarea 3 - Big Data con Apache Spark y Kafka

## Descripcion del proyecto
Proyecto academico de procesamiento de datos de viajes en taxi de Nueva York, usando Apache Spark para analisis Batch y Kafka con Spark Structured Streaming para procesamiento en tiempo real.

## Tecnologias
- Python y PySpark
- Apache Spark
- Apache Kafka
- Matplotlib para graficas

## Archivos principales
- analisis_batch.py: limpieza y analisis por lotes.
- codigo/productor_taxis.py: envia registros al topico viajes-taxi.
- codigo/streaming_taxis.py: procesa mensajes de Kafka con Spark.
- resultados/resumen_por_hora.csv: resultados agrupados por hora.
- resultados/viajes_por_hora.png: grafica del analisis.

## Datos
Los datos de enero de 2025 se conservan localmente en la carpeta datos y no se incluyen en GitHub.
Fuente oficial: https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page
